## 一、策略要解决什么问题

A 股市场风格轮动剧烈:红利与成长此消彼长,A 股与美股周期错位,黄金在风险事件中一枝独秀。
**没有任何一类资产能永远领涨,但永远有某类资产在领涨。**

动量轮动策略的思想是:不去预测谁将走强,而是**承认趋势有惯性**——已经走强的资产,
在短期内继续走强的概率更高。策略定期给股票池里的每只资产"打分",始终持有当前最强的,
强者易位时果断换仓。

问题在于:**用什么标准衡量"强"?** 单一指标容易被偶然波动欺骗(比如一天暴涨就把均线斜率拉爆),
原文的答案是——用三个不同维度的动量因子投票。

## 二、V1 原文策略详解

### 2.1 股票池:四只 ETF 的精心设计

| ETF | 代码 | 角色 | 覆盖逻辑 |
|-----|------|------|---------|
| 红利低波ETF | 512890 | A 股防御 | 熊市/震荡市的避风港,高股息+低波动 |
| 创业板50ETF | 159949 | A 股成长 | 牛市弹性担当,高 Beta |
| 纳指ETF | 513100 | 美股科技 | 与 A 股周期错位,分散单一市场风险 |
| 黄金ETF | 518880 | 商品避险 | 危机行情的对冲,与股票相关性低 |

四只资产两两相关性低,几乎覆盖了"东升/西升/防御/避险"四种宏观情景,
保证**任何行情下池子里都有可轮动的对象**。这是整个策略的地基。

### 2.2 核心:三个动量因子

#### 因子一:乖离动量(偏离趋势)

**衡量价格相对长期均线的偏离程度和变化方向。**

```python
bias = close / MA(close, 20)          # 乖离率:价格 / 20日均线
bias_recent = 最近25天的 bias
y = bias_recent / bias_recent[0]      # 归一化
对 y 做线性回归 → 得分 = 回归斜率 × 10000
```

- 价格向上偏离均线、且偏离越来越大 → 强势加速上涨 → 斜率为正且大;
- 价格向下偏离、且越陷越深 → 弱势下跌 → 斜率为负;
- 它捕捉的是**"强者是否在变得更强"**,而不是静态的"强不强"。

#### 因子二:斜率动量(趋势强度 × 趋势质量)

```python
y = 最近25天收盘价 / 第1天收盘价      # 归一化
对 y 做线性回归 → 斜率 slope,R²
得分 = 10000 × slope × R²
```

这是三个因子里最巧妙的一个。两个标的 25 天都涨了 10%:

- 一个是每天稳步小涨(斜率大、R²≈1)→ 得分高;
- 一个是上蹿下跳最终碰巧涨 10%(斜率大、但 R² 很低)→ 得分被 R² 打折。

**斜率回答"涨得多不多",R² 回答"涨得稳不稳"**,相乘之后,
策略天然偏好"涨得多且涨得稳"的标的。

#### 因子三:效率动量(走势流畅度)

```python
pivot = (开 + 高 + 低 + 收) / 4                          # 当日价格中枢
momentum = 100 × log(pivot[末] / pivot[初])              # 区间对数收益
efficiency = |log(pivot[末]) - log(pivot[初])| / Σ|Δlog(pivot)|   # 净位移/总路程
得分 = momentum × efficiency
```

效率系数来自 Kaufman 的效率比率(Efficiency Ratio)思想:
从 A 点到 B 点,直线到达的效率是 1;反复折返到达,效率趋近 0。

- 同样涨 10%,一路向北的标的效率≈1,三步两回头的可能只有 0.3;
- 它把"涨幅"和"涨法"解耦,**专门惩罚震荡上行的磨人行情**。

#### 为什么要三个因子?(原文的集成学习思想)

三个因子看同一件事的三个侧面:

| 因子 | 回答的问题 | 盲区 |
|------|-----------|------|
| 乖离动量 | 偏离均线还在加剧吗? | 对均线参数敏感 |
| 斜率动量 | 涨得多吗、稳吗? | 对窗口端点敏感 |
| 效率动量 | 涨得流畅吗? | 对跳空不敏感 |

任何一个因子都可能被某段特殊行情骗过,但**三个因子同时被骗的概率低得多**——
这正是机器学习中集成投票(Bagging)的思想:用多样性换取稳定性,降低过拟合风险。

### 2.3 融合:Z-Score 标准化 + 加权

三个因子的量纲天差地别(实测某日原始分:乖离 -34~+16,效率 -4~+2)。
直接相加,乖离因子会凭数值大小垄断话语权。

```python
z = (x - 池内均值) / 池内标准差        # 每个因子各自标准化
综合得分 = 0.3×z(乖离) + 0.3×z(斜率) + 0.4×z(效率)
```

Z-Score 把每个因子转换成"在池子内的相对排名位置",消除量纲后再加权。
权重 0.3/0.3/0.4 是作者在聚宽遍历寻优的结果(效率因子略受倚重)。

### 2.4 调仓阈值:1.5 倍的反人性设计

最朴素的轮动是"谁第一就买谁",但震荡行情里第一名天天换人,会被手续费和假信号磨死。
原文的规矩:

> **挑战者的得分,必须超过持仓者得分的 1.5 倍,才允许换仓。**

- 持仓者 0.8 分、挑战者 1.0 分?不换。优势不够大,可能是噪声;
- 挑战者冲到 1.3 分(>0.8×1.5)?换。优势显著,值得付出交易成本。

这个机制实质是**给换仓决策加了一个"显著性检验"**:只有优势大到不像随机噪声时才行动。
代价是反应变慢——这是所有滤波机制的共性,用滞后换稳定。

### 2.5 实盘机制(QMT 部分的思想)

原文还包含四个贴近实战的设计,本项目也完整实现(`src/etf_rotation/live.py`):

1. **盘前计划**:8:00 先打印当日交易计划(目标、限价、理由),9:30 再执行,心里有底;
2. **限价单**:买价=现价×1.01,卖价=现价×0.99——不用对手价排队,牺牲一点价格换成交确定性;
3. **状态持久化**:持仓、日志、参数落地本地 JSON,程序重启后恢复,便于复盘;
4. **复利盈亏**:每次调仓把此前盈亏并入本金全额投入下一只,而非固定金额。

## 三、V1 的两处硬伤(回撤解剖)

要降回撤,先搞清楚回撤是怎么形成的。逐笔解剖发现两种典型死法:

### 3.1 死法一:浮盈回吐(2024-10,-25.4%)

9·24 行情引爆创业板50,六个交易日 +60%。策略 9-27 追入(0.769),10-08 浮盈约 +57%(收盘约 1.21)。
随后 10-09 单日 **-15.5%**(收 1.023),两周内跌到 0.904。

关键问题:策略有 6% 固定止损,为什么没拦住?
因为固定止损锚定的是**成本价**(0.769×0.94=0.723),而价格从 1.21 跌到 0.904,
始终高于成本线——**止损线根本够不着,57% 的浮盈眼睁睁吐回去大半**。

### 3.2 死法二:震荡绞肉机(2026-06~09,-32.2% 的最大回撤)

四只 ETF 集体无趋势,评分榜首天天换人。策略每次"达标"换仓都是假信号:
7 笔交易 6 亏(-5.4%、-12.4%、-3.3%、+0.9%、-3.0%、-1.1%、-1.8%),钝刀子割肉,
四个月 -32%,至今未修复。

关键问题:策略**永远满仓**——即使全场都是差生,也必须选出班长并把全部身家押上。

## 四、V2 改良策略:三项优化逐项详解

针对两处硬伤,叠加三项机制。**全部默认关闭、可随时开关,V1 逻辑一行未改。**

### 4.1 优化一:移动止损(Trailing Stop)——治"浮盈回吐"

**机制**:不再锚定成本价,而是锚定**持仓期间的最高收盘价**:

```
持仓期间每日更新:peak = max(peak, 今日收盘)
若 今日收盘 < peak × (1 - 8%) → 次日开盘无条件离场
```

回到 2024-10 的场景:peak≈1.21(10-08 收盘),止损线≈1.11。10-09 收盘 1.023 跌破 → 10-10 离场,
把 +57% 的浮盈锁住一大半,而不是等到跌回成本价才反应过来。

**与固定止损的分工**:固定止损管"一买就跌"(入场即错误),
移动止损管"先涨后跌"(盛宴散场)。两者互补,V2 用移动止损正是补上 V1 没有的那半边。

**为什么是 8%**:6~9% 是一个宽平台(年化 21~23%、回撤 -13.3% 几乎不变),
8% 取平台中央,不是调参调出来的尖点;太紧(5%)会被正常波动震出去,太松(15%)等于没有。

### 4.2 优化二:绝对动量过滤(min_momentum)——治"差生里选班长"

**机制**:候选标的近 25 天的**原始收益率 ≤ 0,就不买,宁可空仓**:

```python
if close[-1] / close[-25] - 1 <= 0:
    目标 = 空仓
```

2026-06~09 那种全池阴跌的行情里,策略从"被迫持有最不强硬的下跌资产"变成"持币观望",
直接跳过了绞肉机的大部分。

**实现上的一个关键细节**:这个过滤必须用**原始收益**,不能用综合得分!
综合得分是 Z-Score,是横截面**相对值**——哪怕四只 ETF 全在跌,也总有一个 Z 分最高的
"相对最强者"。用 Z 分做过滤,永远过滤不掉任何东西。只有原始收益(绝对值)
才能表达"全池绝对没有趋势"。这也是"绝对动量"(Absolute Momentum)这个名字的由来,
与相对动量(Relative Momentum,池内互比)构成经典的**双动量**框架:

- 相对动量:谁最强?(原文的三因子加权)
- 绝对动量:它真的强吗?(V2 新增的闸门)

### 4.3 优化三:双持仓(n_hold=2)——治"单吊一只的事件风险"

**机制**:不再全仓押注评分第 1 名,而是**等权持有前 2 名**(各 50%)。

这是三项优化里威力最大的一个,因为它改变的不是规则而是**结构**:
单标的单日 -15% 的暴击(2024-10-09 的创业板50),砸在双持仓组合上只有 -7.5%。
分散不依赖任何预测,是唯一能"免费"降低波动的手段。

配套地,调仓阈值机制自然推广到两个槽位:

- **空槽位**:排名靠前者直接补上(不需要过 1.5 倍阈值);
- **替换在持者**:挑战者得分 > 在持最弱者得分 × 1.5 才换。

一个值得记录的边界:股票池必须大于持仓只数(4 > 2)。
如果池子=2 只还持有 2 只,等于满仓持有全部、永远无需轮动,策略直接退化。

### 4.4 探索过但没进入推荐的机制

诚实记录:以下机制在 60+ 组实验中都试过,有效但非必需,以免堆砌参数:

| 机制 | 效果 | 未入选原因 |
|------|------|-----------|
| 固定止损 6% + 阈值 2.0 | 单持仓下 -32.2%→-25.4%,年化不降反升 | 被移动止损+双持仓的组合覆盖 |
| 均线过滤(MA20/60) | 回撤改善但年化掉到 30% 上下 | 与动量过滤功能重叠且更钝 |
| 入场确认(连续 3 天第一才买) | 单持仓压到 -20.1% 的关键 | 双持仓结构下增量有限 |

它们仍在代码里(`config.py` 风控区),可自行组合探索。

### 5.3 代价要说清楚

1. **年化从 42.5% 降到 25.0%(V2)/ 29.8%(V3.1)**——分散持仓必然稀释攻击性和最强标的的弹性;
2. **换仓更频繁**:双持仓约 35 次往返/年,小资金若有最低 5 元佣金,实际成本高于回测假设;
3. 空仓期资金闲置(回测按 0 利息计,实盘可放货币基金/国债逆回购增强)。

怎么选?一个朴素的判断标准:**V1 的 -32% 回撤你能面不改色拿住,就选 V1;
拿不住,V3.1 的 29.8% 年化 + -12.3% 回撤是更可持续的选择**——
策略收益的最终决定因素,往往是持有人能否熬过最大回撤。
