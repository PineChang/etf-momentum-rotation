## 二、三因子模型(核心)

### 1. 乖离动量因子 —— 价格相对长期均线的偏离趋势

```python
bias = close / close.rolling(window=BIAS_N, min_periods=1).mean()
bias_recent = bias.iloc[-MOMENTUM_DAY:]          # MOMENTUM_DAY = 25(文章给出)
y = bias_recent / bias_recent.iloc[0]
x = np.arange(MOMENTUM_DAY)
LinearRegression().fit(x.reshape(-1,1), y)

```

逻辑:价格向上偏离均线且偏离加强 → 强势上涨;向下偏离且加强 → 弱势下跌。

### 2. 斜率动量因子 —— 趋势强度 × 趋势质量

```python
normalized = close / close.iloc[0]               # 最近 SLOPE_N 天
x = np.arange(1, SLOPE_N + 1)
LinearRegression().fit(x, normalized)
score = 10000 * slope * r_squared                # R² 衡量趋势线性度
```

逻辑:斜率越陡上涨趋势越强;R² 越接近 1 趋势越稳定;两者相乘兼顾强度与质量。

### 3. 效率动量因子 —— 净位移 / 总波动

```python
pivot = (open + high + low + close) / 4          # 价格中枢
momentum = 100 * log(pivot[-1] / pivot[0])
efficiency_ratio = |log(pivot[-1]) - log(pivot[0])| / sum(|diff(log(pivot))|)
score = momentum * efficiency_ratio
```

逻辑:效率系数衡量走势的流畅度,挑选"上涨流畅、震荡较少"的标的。

### 多因子融合的思想(文章观点)

单因子有偶然性;多因子加权融合参考了**集成学习的投票机制**,提高预测稳定性、降低过拟合风险。推广:多策略组合的稳定性优于单一策略,可降低组合回撤。

## 三、Z-Score 标准化

三因子数值范围与分布不同 → 各自转为均值 0、标准差 1 的标准分布后再加权,消除量纲差异,防止某因子因数值过大主导得分。

## 四、调仓阈值机制

即使第二名得分超过第一名也不必然调仓:**挑战者得分 > 持仓得分 × 1.5** 才调仓。
目的:避免震荡期 / 分数接近时频繁出手,降低交易次数。

## 五、QMT 实盘机制

| 机制 | 文章描述 |
|------|---------|
| 时间管理 | 8:00 提前打印当日交易计划;9:30 实际交易 |
| 持久化 | 持仓、交易日志、策略参数落地本地文件,程序重启后恢复,便于复盘 |
| 限价单 | 买入价 = 现价 × 1.01,卖出价 = 现价 × 0.99(不用对手价;资金量小+ETF流动性好,一般在买一至买五成交) |
| 复利盈亏 | 每次调仓后将此前持仓盈亏累加,全额投入下一只,而非固定资金 |
